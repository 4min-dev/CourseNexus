## Обзор системы валидации

Система валидации заданий использует проверку ключевых слов в названии (`title`) и описании (`description`) задания. Проверки выполняются **последовательно** (не параллельно), что создает приоритеты.

1. **Задания на траты** - проверяется ПЕРВЫМ

5. **Задания на избранное**

### 6. Задания на просмотр уроков (Lesson Views)
**Ключевые слова:** `"урок" И "просмотрите"`  
**Метод подсчета:** `COUNT DISTINCT` уникальных уроков  
**Код:** Lines 1047-1054, 1167-1175

```javascript

         (taskTitle.includes("просмотрите") || taskDescription.includes("просмотрите"))) {

    .select({ lessonId: lessonProgress.lessonId })
```

### 7. Задания на завершение курсов (Course Completion)
**Ключевые слова:** `"завершите" И "курс"`  
**Метод подсчета:** `COUNT` курсов где все уроки завершены  
**Код:** Lines 1055-1067, 1176-1189

```javascript
else if ((taskTitle.includes("завершите") || taskDescription.includes("завершите")) && 
         (taskTitle.includes("курс") || taskDescription.includes("курс"))) {
  const completedCourses = await db
    .select({ courseId, completed, total })
    .from(lessonProgress)
    .where(eq(lessonProgress.userId, userId))
    .groupBy(lessonProgress.courseId)
    .having(sql`COUNT(CASE WHEN ${lessonProgress.isCompleted} = true THEN 1 END) = COUNT(*)`);
  currentProgress = completedCourses.length;
}
```

✅ **Правильно:** Используется COUNT курсов с 100% завершением

### 8. Задания на дни на платформе (Days on Platform)
**Ключевые слова:** `"дн" И ("проведите" ИЛИ "платформ")`

**Код:** Lines 1068-1078, 1190-1200

```javascript
else if ((taskTitle.includes("дн") || taskDescription.includes("дн")) && 
         (taskTitle.includes("проведите") || taskDescription.includes("проведите") || 
          taskTitle.includes("платформ") || taskDescription.includes("платформ"))) {

  if (user?.createdAt) {

}
```

✅ **Правильно:** Используется разница дат

## Выявленные конфликты

### ❌ КОНФЛИКТ 1: Задания с временными рамками
**Проблемные задания:** #5, #6, #7, #47

Задания с временными требованиями (сегодня, за неделю, за день) **НЕ учитывают временной контекст**.

**Пример:**
- Задание: "Активный день - 3 урока за сегодня"
- Валидация срабатывает: "урок" + "просмотрите"
- Показывает: Все просмотренные уроки за все время
- **Должно показывать:** Только уроки просмотренные сегодня

**Рекомендация:** Добавить временные фильтры в запросы к БД на основе ключевых слов "сегодня", "за день", "за неделю".

---

### ❌ КОНФЛИКТ 2: Дни подряд vs Дни на платформе
**Проблемные задания:** #43, #44

Задания на "дни подряд" (streak) используют **ту же валидацию** что и "дни на платформе".

**Пример:**
- Задание #43: "30 дней подряд"
- Валидация срабатывает: "дн" + "проведите"
- Показывает: Количество дней с регистрации (например, 45 дней)
- **Должно показывать:** Текущий streak активности (например, 3 дня подряд)

**Рекомендация:** Добавить новую валидацию с ключевым словом "подряд" и системой трекинга streak.

---

### ❌ КОНФЛИКТ 3: Щедрый друг
**Проблемное задание:** #49

Задание "Щедрый друг - друг купил курс" валидируется как обычное реферальное задание.

**Пример:**
- Задание: "Щедрый друг - друг купил курс"
- Валидация срабатывает: "друг" → считает рефералов
- Показывает: 4/1 (4 реферала)
- **Должно показывать:** Количество рефералов с хотя бы 1 покупкой

**Рекомендация:** Добавить новую валидацию с ключевыми словами "друг" + "купил" и JOIN на таблицу purchases.
